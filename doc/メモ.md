## 注意

- **APIキーの期限は 2026-11-11 ごろ**。切れたら Claude Console で作り直して `keys.json` に入れる。クレジットは Max プラン特典で毎月 $100（約1か月で失効、自動チャージなし）。
- **外部サーバーやマルチプレイに繋ぐときは `allow_insecure_coding` を false に戻す**（他人のチャット経由でコードを実行させられる恐れ）。
- **mineflayer と minecraft-data は同じ時期の版を組み合わせる**。片方だけ固定すると通信の形が食い違って壊れる（ダメージで退出する不具合の原因だった）。
- 退出・切断したら、まず Minecraft 側のログ（`~/Library/Application Support/minecraft/logs/latest.log`）を見る。

## 既知の不具合（未対応）

- 地下から地上に出られないことがある。`!goToSurface` は真上の一番高いブロックへの経路探索だけで、上に掘るコマンドもない。
- `!newAction` のコード実行中に自動行動（戦闘など）が割り込み、コードが10秒以内に止まらないと、プロセスが強制終了 → 約1秒で自動再起動（本家の安全装置）。実行中の作業は失われる。
- クラフトがたまに `Event updateSlot:0 did not fire within timeout of 20000ms` で失敗し、持ち物や作業台の認識がずれる（mineflayer 本家 issue #3906 と同系統）。作業台を置き直すか bot を再起動すると直る。
- `giveToPlayer` の受け渡しがときどき「never received」で失敗する（アイテムは相手の手前に落ちる）。ユーザーは困っていないので保留。
- 記憶の保存などは会話を空で送るため、ユーザー発言が `_` だけになる。
- 自動アイテム回収中に別の行動を命じたときの `PathStopped` エラー表示は無害。
